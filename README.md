# kombinasi-bundling-produk-cpp
Program ini dibuat untuk mengaplikasikan konsep kombinatorial sebagai solusi dalam permasalahan sehari-hari, khususnya pada bisnis makanan. 
Program ini membantu menentukan berbagai kombinasi bundling produk serta memilih paket dengan profit paling menguntungkan bagi pengguna.

Program ini mampu:
Menentukan seluruh kemungkinan kombinasi bundling produk
Menghitung profit dari setiap kombinasi
Menentukan paket bundling dengan keuntungan paling maksimal

# Konsep yang Digunakan

Kombinasi (C(n,r))
Algoritma Rekursif
Perhitungan Profit (Harga - Modal)

# Rumus yang Digunakan

Total kombinasi dihitung menggunakan:

[
C(n,r) = \frac{n!}{r!(n-r)!}
]

# Cara Kerja Program

User memasukkan jumlah produk
User menginput data setiap produk:
Nama produk
Modal
Harga jual
User menentukan jumlah produk dalam satu paket (r)
Program akan:
Menampilkan semua kombinasi bundling
Menghitung profit setiap kombinasi
Menampilkan kombinasi terbaik (profit maksimum)

# Tujuan

Sebagai implementasi materi kombinatorial dalam bentuk program nyata yang dapat membantu pengambilan keputusan dalam bisnis.
